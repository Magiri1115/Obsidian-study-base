Dataview を使った「学習ダッシュボード」の**前準備**、**ダッシュボードの配置・コード**、そして**日常の使い方・見方**をまとめます。

[[ダッシュボード]]

### 1. 前準備（これを先にやっておくと集計が機能する）

Dataview はノートに書かれた「プロパティ（YAML）」や「タグ」を読み取って一覧を作るため、先に最小限のルールを決めておきます。

#### ① プラグイン設定の確認

- **Dataview** が有効化されていること（`image_f54d02.png` にて有効化済みを確認）。

- 設定 ＞ Dataview で **Enable Inline Queries**（必要に応じて **Enable JavaScript Queries**）がオンになっていること。

#### ② 過去問・論点ノートに入れるプロパティのルール

新規ノートを作る際、冒頭に以下のプロパティを置きます（手入力でも、標準のコアプラグイン「テンプレート」で挿入してもOKです）。

```YAML
---

category: 午後1
topic: トランザクション
status: 未復習

---
---

- **`category`**：`午前1` / `午前2` / `午後1` / `午後2` / `知識整理` など（試験区分・種別）

- **`topic`**：`論理設計` / `物理設計` / `SQL` / `トランザクション` / `障害回復` など（単元・テーマ）

- **`status`**：`未復習` / `復習中` / `完了` など（演習・理解の進捗）
  
詳細は[[ダッシュボード使い方]]を参照。

---
```

#### ③ ミス・弱点タグのルール

問題演習や論点メモの中で「引っかかったポイント」や「見落とした前提」があったら、本文またはプロパティのタグに `ミス/` 始まりのタグを付けます。

- 例：`#ミス/前提見落とし`、`#ミス/排他・ロック漏れ`、`#ミス/正規化過剰・不足`

### 2. ダッシュボードノートの作成

たとえば `DBスペシャリスト/00_ロードマップ・出題傾向/学習ダッシュボード.md` を作成し、以下の内容を貼り付けます。

````Markdown
# DBスペシャリスト 学習ダッシュボード

## 1. これから復習するノート（未復習・復習中）
```dataview
TABLE category AS "区分", topic AS "分野", status AS "状態", dateformat(file.mtime, "yyyy-MM-dd HH:mm") AS "最終更新"
FROM "DBスペシャリスト"
WHERE status != "完了" AND status != null
SORT file.mtime DESC
```

## 2. ミス・弱点タグ付きのノート
```dataview
TABLE category AS "区分", topic AS "分野", file.tags AS "タグ"
FROM "DBスペシャリスト"
WHERE contains(file.tags, "ミス/")
SORT file.mtime DESC
```

## 3. 最近更新したノート（直近10件）
```dataview
TABLE category AS "区分", status AS "状態", dateformat(file.mtime, "yyyy-MM-dd HH:mm") AS "更新日時"
FROM "DBスペシャリスト"
LIMIT 10
SORT file.mtime DESC
```
````

### 3. ダッシュボードの見方

開いたとき、3つのブロックそれぞれで**見るべき目的**が異なります。

**① これから復習するノート**

- **見方**：`status` が `完了` 以外のノートが「直近で触った順（`SORT file.mtime DESC`）」に並びます。

- **意図**：解きっぱなしや書きっぱなしを放置せず、「次に何を解き直すか・詰め直すか」を迷わず決めるためのToDoリストです。

**② ミス・弱点タグ付きのノート**

- **見方**：`#ミス/...` タグが付いているノートと、そのタグ一覧が表示されます。

- **意図**：単元ごとではなく「自分の思考のクセ・落とし穴」単位で振り返るための弱点集です。試験直前や週末の総点検で重宝します。

**③ 最近更新したノート（直近10件）**

- **見方**：`DBスペシャリスト` フォルダ内で最近編集されたノートが10件表示されます。

- **意図**：プロパティ（`status` など）をまだ設定していないメモや、昨日の作業の続きをすぐ開きたいときの「直近履歴」として使えます。


### 4. 日常の使い方（1サイクルの流れ）

1. **書く**：過去問演習や論点整理のノートを作り、本文を書く＋冒頭に `category` / `topic` / `status: 未復習` を書く。

2. **印をつける**：間違えた問題やハマった点があれば `#ミス/〇〇` タグを残す。

3. **ダッシュボードを見る**：学習開始時や週末にダッシュボードを開き、「未復習・復習中」や「ミス・弱点タグ付き」から対象ノートをクリックして開く。

4. **状態を更新する**：解き直しや理解の整理が終わったら、そのノートの `status` を `完了` に書き換える。ダッシュボードに戻ると「これから復習するノート」から自動で消える。

### 運用をラクにするコツ

- **最初から全ノートに完璧なプロパティを付けない**：まずは新しく作る過去問・重要論点ノートから `status` を付けるだけでも十分回ります。

- **よく使う絞り込みはクエリを1行足す**：たとえば「午後1の未復習だけ見たい」ときは `WHERE status != "完了" AND status != null AND category = "午後1"` のように条件を足すと、目的に合わせたビューをすぐ作れます。


まずは過去問や論点ノートを1〜2個 `status: 未復習` で作成し、ダッシュボード上で一覧に出るか確認してみてください。どの項目を一番重視して管理したいか（例：午後1の演習進捗、ミスの型、単元別の網羅度など）があれば、それに合わせてクエリも調整できます。
